Scope and data

ClassVela (com.christools.timetable) is provided by Chris Tools Studio. This policy covers the current Android timetable app. Course names, teachers, rooms, times, term dates, week patterns, colors, reminders and settings stay on your device. The app does not upload them to the developer or third parties, sell them, or use them for advertising. It has no accounts, cloud sync, ads, analytics, crash-reporting SDKs or Internet permission.

Permissions and device features

Notifications are optional and used only for class reminders you configure. Reboot and date, time or time-zone events rebuild local reminders. Denying notifications does not prevent timetable use. Backup import and export use the Android system file picker only after you choose the action; the app accesses the file you select and does not request broad storage, camera, location or contacts access. It does not read the clipboard.

On Android 12 and later, optional Alarms & reminders special access schedules your chosen class reminders precisely. Without it, Android may delay reminders. Granting or denying this access does not change local data handling or prevent timetable use.

Storage, backups and security

App data is kept in Android app-private storage protected by Android access controls. Course and settings preferences are excluded from Android cloud backup and device transfer. Exported backup files are not encrypted; anyone with a copy may read the timetable. You control where backups are saved and who can access them. If you choose a cloud storage provider in the file picker, that provider handles the file under its own policy.

Retention and deletion

Clear all courses removes course entries but retains timetable and app settings. Clearing app storage in Android settings or uninstalling removes local app data. Exported backup files are separate and must be deleted from the storage location you selected. There is no developer-held timetable account or server copy to delete.

Online policy and support

The app shows an offline privacy notice and does not open a browser from that notice. This public policy is hosted on GitHub Pages for people visiting it separately, for example from Google Play. No timetable contents or app device identifiers are sent to this website by the app. GitHub logs visitors’ IP addresses for security purposes; its privacy statement applies to hosting. If you email support, your email address and message are processed to answer your request and retained as needed for that request and applicable obligations. You may request deletion through the same address. Sending email is optional; avoid including unnecessary personal or course information.

Audience

ClassVela is a course-planning tool for students and other timetable users. It does not ask for age or date of birth. If you believe a child has sent personal information to support, contact us to request its removal.

Changes and contact

If a future version changes data handling or adds accounts, cloud sync, advertising, payments, analytics or crash reporting, this policy and the Google Play Data safety declaration will be updated before that version is released. Material changes will be communicated in the app or by another appropriate method. Developer: Chris Tools Studio. Privacy questions and requests: liu.dev2026@gmail.com.

通知は任意で、設定した授業のリマインダーにのみ使用します。再起動や日付・時刻・タイムゾーンの変更後にローカル通知を再設定します。通知を拒否しても時間割は使えます。バックアップの読み込みと書き出しは、操作を選んだ場合に Android のファイル選択画面で選択したファイルだけにアクセスします。広範なストレージ、カメラ、位置情報、連絡先の権限は要求せず、クリップボードも読みません。

Android 12 以降では、任意の「アラームとリマインダー」への特別なアクセスを許可すると、選択した授業通知を正確に設定できます。許可しない場合、Android が通知を遅らせることがあります。許可の有無により端末内のデータ処理は変わらず、時間割も引き続き利用できます。

保存、バックアップ、安全性

データは Android のアクセス制御で保護されたアプリ専用領域に保存します。授業と設定の保存ファイルは Android のクラウドバックアップと端末間移行の対象外です。書き出したファイルは暗号化されていないため、コピーを持つ人は時間割を読める場合があります。保存先とアクセス権は利用者が管理します。クラウド保存先を選ぶ場合、その事業者のポリシーが適用されます。

保持と削除

すべての授業を削除しても時間割とアプリの設定は残ります。Android 設定でアプリのストレージを消去するかアンインストールするとローカルデータを削除できます。書き出したバックアップは保存先で別途削除してください。開発者が保持する時間割アカウントやサーバー上のコピーはありません。

オンラインポリシーとサポート

アプリ内にはオフラインのプライバシー説明を表示し、そこからブラウザーを開くことはありません。この公開ポリシーは、Google Play からのアクセスなど、別途閲覧する方のために GitHub Pages で公開しています。アプリからこのサイトに時間割の内容や端末識別子を送信することはありません。GitHub はセキュリティ目的で訪問者の IP アドレスを記録し、ホスティングには同社のプライバシー声明が適用されます。サポートにメールを送ると、メールアドレスと内容を対応のため処理し、問い合わせと適用される義務に必要な期間保持します。同じアドレスに削除を依頼できます。連絡は任意です。不要な個人情報や授業情報を送らないでください。

利用者

ClassVela は学生など時間割を使う方の授業計画を支援します。年齢や生年月日は求めません。子どもがサポートに個人情報を送ったと思われる場合は、削除をご依頼ください。
